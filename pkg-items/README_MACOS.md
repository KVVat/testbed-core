# TestBed Core for macOS

## How to Run

1.  Double-click `TestBed Core.app` to run it.
2.  The application will start.

## Notes

On macOS, you might see a dialog saying "TestBed Core.app can't be opened because it is from an unidentified developer." In that case, please follow these steps to open the application:

1.  Right-click (or Control-click) on `TestBed Core.app`.
2.  Select "Open" from the context menu.
3.  Click "Open" again in the dialog that appears.
